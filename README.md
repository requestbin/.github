**RequestBin** helps developers, researchers, and security teams **capture, inspect, and debug requests**—from webhooks to OAST flows—via a **cloud-first platform** and **developer-friendly tooling**.

> **Latest:** **RequestBin v3.0**
>
> - Zero-loss **cloud migration**
> - **Smart request management** (read/unread, important flags, free-text filters)
> - **Custom OAST servers** (add and manage your own)
> - Modern UI (dark/light), real-time streaming, improved JSON/XML formatting
> - Enterprise security (SSO, MFA, RBAC, audit logs, encryption)

## 🧰 Projects

### 🟢 RequestBin.net

Capture and inspect HTTP/DNS requests with a single URL. Share bins, analyze payloads, replay requests, and integrate with CI/CD.

- 🔄 **Cloud Migration** with integrity checks and rollback  
- 🧭 **Smart request management**: read/unread, important flags, free-text search  
- ☁️ **Custom OAST**: use the global server or add your own private servers  
- 🛡 **Enterprise**: SSO, MFA, RBAC, audit logs, encryption

**Start here:** https://requestbin.net  
**Release post:** https://blog.requestbin.net/introducing-requestbin-v3-0-cloud-migration-revamped-ui-and-enterprise-grade-security/

### 🔧 RequestBin Collaborator Plugin for BurpSuite

A lightweight extension that brings **RequestBin-powered collaboration** to BurpSuite—ideal for **OAST, webhook testing, red teaming**, and bug bounties.

- Works like Burp Collaborator, powered by **RequestBin** endpoints  
- Plug-and-play with your RequestBin (global or custom OAST)  
- Great for out-of-band findings, callbacks, and webhook flows

**Repo:** https://github.com/requestbin/requestbin-collaborator

```bash
# Quick start (example)
# 1) Download the .jar from Releases
# 2) BurpSuite → Extender → Extensions → Add → Select JAR
# 3) Configure your RequestBin endpoint (global or custom OAST)
```
